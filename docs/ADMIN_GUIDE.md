# Admin guide

Go to **www.bigsa.bt/admin** and sign in with the email and password another admin gave you. The public website never asks anyone to sign in; only `/admin` does. Change your password under **Account** the first time.

## Daily work

**Dashboard.** New applications, unread messages and anything still to do. Red tiles need attention.

**Applications.** Every online submission, newest first. Search by reference, name, email or any answer, and filter by form, status or date. Open one to:
* read every answer, with the player list as a table, and download attachments;
* change its status (Received → Under review → More information needed → Approved / Not approved). Tick *Email the applicant* to tell them, and add a message if useful;
* add internal notes, which only staff can see.

To export, choose a form in the filter, then **Export CSV**. The file opens in Excel with Dzongkha names intact.

**Messages.** Enquiries from Contact us. Use **Reply by email** to answer from your mail client.

## Publishing

**News.** **New article** → title, summary, text, cover photo, category. Click **Save draft** to keep it private, or **Publish** to put it live. A future publish date schedules it. *Feature on the home page* puts it first.

Text formatting: `## Heading`, `**bold**`, `*italic*`, `[link text](https://…)`, and lines starting with `- ` for lists. Use **Preview** to check.

**Events & archive.** Add tournaments with dates and a venue. They show as upcoming until the end date, then move to the archive. Afterwards, add results and a photo album.

**Sports.** Each game's page: summary, history, how it's played, cultural significance, key numbers, scoring, equipment, rules and photos. A sport shows as *in preparation* until its summary is filled in. Scoring rules named Karey, Gorthig, Sa-karey, Daya, Dhobji or Zhecha-gam light up the matching part of the interactive target. Add a new game with **New sport**, and reorder with the arrows.

**Rules** are entered one article at a time; each line becomes a numbered clause.

**Who's who.** Staff profiles in display order. Add contact details only where approved for public display.

**Documents.** Upload rules, standards, frameworks, forms, reports and notices. Each one has a category and an optional sport, and download counts are recorded.

**Media library.** All photos and documents. Add a description to every photo (for people using screen readers), tick *Show in the home-page photo gallery* to feature one, and add credits.

## Online forms

**Online forms** lists every form. Use the switch to turn a form on or off instantly. Open a form to:
* set opening and closing dates (Bhutan time), so it opens and closes by itself;
* edit eligibility, requirements, instructions and FAQs;
* add, remove, reorder or change questions. Types include short and long text, email, phone, CID (11 digits), number, date, dropdown, choose one, choose several, tick box, file upload, and a table of rows (for example players, with a minimum and maximum count);
* add extra email addresses to notify for each new submission.

Keep the consent tick box in the last step. A form that already has applications can't be deleted, only switched off, so its records stay intact.

## Site content and users

**Site content.** Who we are text, vision, mission and values, contact details, map location, social links, and the launch checklist.

**Admin accounts.** Add another admin, reset a password, or deactivate a leaver; deactivation signs them out everywhere at once. Every admin has full access. **Audit log** shows who did what and when.
